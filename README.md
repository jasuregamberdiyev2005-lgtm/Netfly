# Netlify site

1. `config.js` ichidagi `window.BACKEND_URL` ni Railway backend domeniga almashtiring.
2. `netlify_site` papkasini Netlify'ga deploy qiling. Netlify manual deploy uchun loyiha papkasini drag-and-drop qilishni qo'llab-quvvatlaydi.
3. `image.svg` o'rniga o'zingiz xohlagan bitta rasmni qo'yishingiz mumkin; `index.html` dagi `src` nomini moslang.

Kamera ishlashi uchun sayt HTTPS orqali ochilishi kerak.
